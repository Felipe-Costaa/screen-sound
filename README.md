# ScreenSound 🎵

ScreenSound is a C# console application designed to manage a music catalog. It allows users to register their favorite bands, submit ratings, and view dynamically calculated average scores. 

This project was developed as a hands-on application to solidify foundational programming concepts in C# and .NET.

## 🚀 Features

- **Register Bands:** Add new bands to the application's catalog.
- **Display Bands:** View a complete list of all registered bands.
- **Evaluate Bands:** Assign numerical ratings to specific bands.
- **Calculate Averages:** Automatically calculate and display the overall average rating for any given band based on user inputs.
- **Interactive Menu:** Navigate through the application using a clean, terminal-based menu.

## 💻 Tech Stack & Concepts Applied

This project relies on core C# features without the use of external frameworks, focusing on building a strong foundation in programming logic:

- **C# / .NET:** Primary language and runtime environment.
- **Dictionaries & Lists:** Used extensively for managing state, storing band names in memory, and associating multiple ratings with specific bands.
- **Functions (Methods):** Code is modularized into reusable functions to handle distinct responsibilities (e.g., displaying the menu, calculating averages).
- **Control Flow:** 
  - `switch` statements for efficient menu navigation.
  - `for` and `foreach` loops for iterating over collections and displaying data.

## 🛠️ How to Run Locally

### Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine.

### Installation & Execution

1. Clone this repository:
   bash
   `git clone [https://github.com/Felipe-Costaa/screensound.git](https://github.com/Felipe-Costaa/screensound.git)`
2. Navigate to the project directory:
   bash
  `cd screen-sound;`
3. Run the application using the .NET CLI:
   bash
  `dotnet run`
